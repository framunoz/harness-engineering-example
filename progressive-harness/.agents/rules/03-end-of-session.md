# End of Session Rules

When meaningful work occurred:

1. Create or update `.agents/LOGS/sessions/<session-id>.md` with scope, changes, verification, and blockers.
2. Append a compact entry to `.agents/progress/HISTORY.md` linking the full session log.
3. Update `.agents/progress/CURRENT.md` to accurate next-session live state.
4. Update `.agents/progress/feature_list.json` statuses and evidence.
5. Record unresolved blockers and escalation needs.
6. Update `docs/README.md` if docs were added/removed/changed.

If no meaningful work occurred, keep updates minimal but ensure state remains truthful.
