# Working Rules

- Work one feature at a time.
- Keep at most one `in_progress` feature in `.agents/progress/feature_list.json`; when actively implementing, exactly one active feature should be marked `in_progress`.
- Update `.agents/progress/CURRENT.md` during work with live state, blockers, and next action.
- Keep feature status accurate (`pending`, `in_progress`, `blocked`, `done`) and maintain evidence for completed work.
- Evaluate documentation impact each iteration; if behavior/setup/operations/architecture/testing changed, update `docs/` and index.
- Keep repository in a clean, restartable state for the next session.
